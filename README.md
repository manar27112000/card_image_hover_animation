# Card Image Hover Animation

A simple HTML/CSS project that displays team member cards with hover effects. When you hover over a card, the image shrinks and additional information with social icons appears.

## Features

- Responsive card layout
- Smooth image hover animation
- Shows name, role, and social icons on hover
- Uses Font Awesome icons

## Technologies Used

- HTML5
- CSS3
- Font Awesome (for social icons)
